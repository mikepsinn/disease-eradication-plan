# Academic Journal Transformation (Formal + Rigorous)

**Target**: Health Economics, Health Affairs, PLOS Medicine, academic journals

## PRESERVE (DO NOT MODIFY)
- ALL numbers, statistics, calculations, formulas
- ALL citations `[text](../references.qmd#anchor)`
- Core arguments and evidence
- Methodological details and data sources
- Document structure (headings, lists, tables, equations)

## REMOVE
- ALL humor, sarcasm, rhetorical flourishes
- Second-person ("you") and first-person ("I")
- Emotional appeals and value judgments without evidence
- Casual examples, metaphors, asides
- Rhetorical questions
- Exclamation points
- Contractions ("don't", "it's")

## TRANSFORM

| Informal | Academic |
|----------|----------|
| "Here's some math. Don't worry..." | "The following quantitative analysis..." |
| "You might argue..." | "Critics may contend..." |
| "Your Tiny Sandbox" | "Current Scope of Approved Therapeutics" |
| "The Math You're Ignoring" | "Quantitative Analysis of Unexplored Therapeutic Space" |
| "parking lot of Disney World" | "preliminary stage of potential exploration" |
| "stuff you could test tomorrow" | "interventions amenable to immediate evaluation" |
| "Pink ribbons are better at lobbying..." | "Funding correlates more with advocacy infrastructure (r=0.73) than disease burden (r=0.07)" |

## Required Tone
- Third-person perspective only
- Formal academic vocabulary
- Neutral, objective, evidence-based
- Precise technical language
- No emotional content

## Section Headings: Academic Style
Use formal descriptive titles. Replace informal/sarcastic headings with standard academic structure.

Return complete transformed text. Third-person throughout. Formal prose only. Preserve all citations and data.
