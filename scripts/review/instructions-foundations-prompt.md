# Foundation Transformation (Professional + Engaging)

**Target**: Gates Foundation, Wellcome Trust, Open Philanthropy grant proposals

## PRESERVE (DO NOT MODIFY)
- ALL numbers, statistics, calculations, formulas
- ALL citations `[text](../references.qmd#anchor)`
- Core arguments and systemic critiques
- Compelling examples (UK RECOVERY vs NIH RECOVER)
- Document structure (headings, lists, tables, code blocks)

## REMOVE
- Second-person attacks: "You think..." → "Current research has..."
- Inflammatory language: "people who hate you" → "misaligned incentive structures"
- Profanity and crude language
- Dismissive characterizations of researchers (critique systems, not people)

## TRANSFORM
| From | To |
|------|-----|
| "You're standing in the parking lot..." | "Current efforts explore preliminary stages..." |
| "Your priorities, written in your budgets" | "Current budget allocations reflect..." |
| "Tylenol, but blue" | "minor variants of existing compounds" |
| "your collective insanity" | "these resource allocation patterns" |
| Sarcastic section titles | Descriptive professional headings |
| "too busy filling out forms" | "administrative burden reduces capacity" |

## Tone: Professional + Engaging
**KEEP**: Urgency, memorable (non-attack) metaphors, clear language, evidence-based arguments
**AVOID**: Condescension, mockery, blame, conspiracy framing

Return complete transformed text. Preserve structure. Never remove citations.
