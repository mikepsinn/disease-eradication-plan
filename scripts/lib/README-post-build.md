# Quarto Post-Build Processing

Generic post-render processing for any Quarto site configuration.

## Overview

The `quarto_post_build.py` module provides **generic, reusable functions** for:
1. **PDF post-processing** - Find and move PDFs to correct locations
2. **HTML link rewriting** - Convert cross-site links to absolute URLs

## Generic Functions

### `postprocess_pdf()`

Finds PDFs generated by Quarto and moves them to the correct location.

**Features:**
- ✅ Auto-detects PDF filename from Quarto config
- ✅ Searches project root and build directory
- ✅ Customizable search patterns
- ✅ Works with any Quarto config

**Example 1: Auto-detect PDF name from config**
```python
from quarto_post_build import postprocess_pdf

# PDF filename auto-detected from _quarto-mysite.yml -> format.pdf.output-file
postprocess_pdf(
    build_dir="_site/mysite",
    config_file="_quarto-mysite.yml"
)
```

**Example 2: Explicit PDF name**
```python
postprocess_pdf(
    build_dir="_site/mysite",
    expected_pdf="my-document.pdf"
)
```

**Example 3: Custom search patterns**
```python
postprocess_pdf(
    build_dir="_site/mysite",
    config_file="_quarto-mysite.yml",
    search_patterns=["My*.pdf", "Document*.pdf"]  # Custom patterns
)
```

### `postprocess_html_links()`

Rewrites cross-site links in HTML files as absolute URLs.

**Use case:** When you have multiple Quarto sites (e.g., economics, book) and want links from one site to point to absolute URLs of another site.

**Example:**
```python
from quarto_post_build import postprocess_html_links

# Rewrite links from economics site -> book site
postprocess_html_links(
    build_dir="_site/economics",
    source_config="_quarto-economics.yml",  # Files in this config
    target_config="_quarto-book.yml",       # Links to these become absolute
    target_url="https://manual.example.org" # Base URL for target
)
```

**How it works:**
1. Extracts file lists from both configs
2. Finds all `.qmd` links in HTML
3. If link is in `target_config` but NOT in `source_config`, converts to absolute URL
4. Otherwise, converts `.qmd` → `.html` (relative)

## Site-Specific Convenience Functions

Pre-configured functions for common sites (all auto-detect PDF names):

```python
from quarto_post_build import (
    postprocess_economics_html,  # Economics HTML + PDF
    postprocess_economics_pdf,
    postprocess_book_pdf,        # Book PDF
    postprocess_wishocracy_pdf,  # Wishocracy paper PDF

postprocess_wishocracy_pdf(build_dir="_site/wishocracy")
```

## Integration Example

Integrate into a render script:

```python
#!/usr/bin/env python3
import sys
from pathlib import Path

# Add lib to path
sys.path.insert(0, str(Path(__file__).parent / "lib"))
from quarto_pre_build import prepare_mysite  # Your pre-build function
from quarto_post_build import postprocess_pdf

def main():
    # Pre-build: Setup config and index files
    if not prepare_mysite():
        sys.exit(1)
    
    # Render (your Quarto render command here)
    # ...
    
    # Post-build: Fix PDF location
    if not postprocess_pdf(
        build_dir="_site/mysite",
        config_file="_quarto-mysite.yml"
    ):
        sys.exit(1)
    
    print("✓ Build complete!")

if __name__ == "__main__":
    main()
```

## How PDF Auto-Detection Works

When `config_file` is provided but `expected_pdf` is not:

1. Reads the Quarto YAML config
2. Extracts `format.pdf.output-file` value
3. Uses that as the target PDF filename

Example config:
```yaml
# _quarto-mysite.yml
format:
  pdf:
    output-file: "my-awesome-document.pdf"  # ← Auto-detected
```

## Error Handling

All functions return `bool`:
- `True` = Success
- `False` = Failure (details printed if `verbose=True`)

```python
if not postprocess_pdf(build_dir="_site/mysite"):
    print("PDF post-processing failed!")
    sys.exit(1)
```

## Backwards Compatibility

Old function names still work:
```python
# These are just wrappers to the generic functions
postprocess_economics_html()  # → postprocess_html_links(...)
postprocess_economics_pdf()   # → postprocess_pdf(...)
```

## Why Generic?

**Before:** Separate functions for each site (code duplication)
```python
def postprocess_economics_pdf(): ...
def postprocess_wishocracy_pdf(): ...
def postprocess_iab_pdf(): ...  # All doing the same thing!
```

**After:** One generic function, reusable for all
```python
postprocess_pdf(build_dir="...", config_file="...")  # Works for any site!
```
