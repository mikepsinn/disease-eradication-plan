# Cut-out registry

One name per cut-out, used by every storyboard and by `video/tools/art-gen.sh`. Draw each one once, on one sheet, with the poses and states in its row. A state with its own name (`you-skeleton`) is a separate WebP on the same sheet. Words on signs, tags, labels and screens are code, never art. "Exists" means a file is already in `video/assets/art/collage/` (or `reaper/`, `deck/`, `console/`) under that name; existing files keep their names.

Host props (the case file, the mug, the stamp, the Calculator, the Optimitron and the other things on the console) are drawn in the host style by `KIT.studio` and `KIT.props`; they are listed here only when a plate also needs them as cut-outs.
