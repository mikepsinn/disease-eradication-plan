# Cartoon video: "How to End War and Disease (for Busy People)"

Plan and timing files for a cartoon video of audiobook episode 1 (chapter slug `index-manual`). The audiobook MP3 is the voice track; no new narration is recorded.

| File | What it is |
|---|---|
| `AGENTS.md` | How a part gets made, step by step, and the rules that are easy to get wrong. Start here. |
| `cartoon-style-bible.md` | The look (two visual layers), Wishonia's sprites, layout and lip-sync, the other characters, real people and brands, and how to build the video. |
| `transcript.md` | Full transcript, one paragraph at a time, each with its [HH:MM:SS] time. Generated by `video/tools/word-timings.mjs`. |
| `transcript.srt` | Subtitles for the full episode (1,094 cues). Generated by `video/tools/word-timings.mjs`. |
| `word-timings.json` | Start and end time of every spoken word, for scene times, lip-sync and captions. Generated by `video/tools/word-timings.mjs`. |
| `wishonia-contact-sheet.png` | All 59 Wishonia sprites from `transmit/public/assets/sprites/alien/`, with their file names. |
| `video/` | The HyperFrames project that renders the cartoon (HTML + GSAP to MP4). The storyboards are in `video/storyboards/`, one per part. The Part 2 pilot ("Hello, human") animates narration that is no longer in the audio. See `video/README.md`. |

## Source audio

`https://static.warondisease.org/assets/audiobook/manual-paperback/mp3/index-manual.cbaf659d.mp3` (57:53, item 1 of `https://static.warondisease.org/assets/audiobook/manual-paperback/feed.xml`).

## Notes

- The MP3 is the theme song (99.98 s, with the cold open in it), then the chapter, then the outro. The theme song has not changed since March 2026, so the cold open and the title sequence keep their old times.
- The timings come from the audiobook pipeline's forced alignment of the chapter against the text it was voiced from, moved by the length of the theme song. Rebuild them with `node video/tools/word-timings.mjs <path to assets/audiobook/manual-paperback>` in a checkout that has built the audiobook. The cold open's words are kept from the earlier Whisper transcript.
- The narration spells numbers out ("six hundred and four"), so a cue on a number is the spoken words. On-screen numbers use digits.
