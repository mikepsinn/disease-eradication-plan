## PDFs To Prepare

## Formatting Rules

- Do not paste Markdown link syntax into Google Form text boxes. Paste `https://...` URLs.
- Do not paste QMD filenames like `(health-dividend.qmd)` into the form unless they are explanatory text. In the long-form PDF, use rendered links instead.
- In short paragraph answers, cite only when it changes credibility. Otherwise point reviewers to the long-form attachment and public papers index.
- Before checking the form's functional-link acknowledgment, open every public URL in a private/incognito browser or signed-out session.
